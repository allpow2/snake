# 贪吃蛇游戏 — 项目需求与技术方案

## 一、项目概述

基于 Python + Pygame 实现经典贪吃蛇游戏，采用模块化架构，最终沉淀为可复用的 skill.md 模板。

## 二、功能需求

### 2.1 核心玩法
| 功能 | 描述 |
|------|------|
| 蛇的移动 | 上下左右四方向，支持方向键和 WASD |
| 食物生成 | 随机位置生成食物，不与蛇身重叠 |
| 吃食物 | 蛇头碰到食物 → 蛇身增长 1 节 + 分数增加 |
| 碰撞检测 | 撞墙 或 撞自己 → 游戏结束 |
| 分数系统 | 实时显示当前分数，记录历史最高分 |

### 2.2 交互功能
| 功能 | 描述 |
|------|------|
| 暂停/继续 | 按 Space / P 暂停，再按继续 |
| 重新开始 | 游戏结束后按 R 重新开始 |
| 退出 | 按 Esc 或关闭窗口退出 |
| 难度递增 | 可选：每吃 N 个食物，蛇移动速度略微提升 |

### 2.3 界面展示
| 元素 | 描述 |
|------|------|
| 游戏区域 | 固定网格大小，蛇和食物按网格对齐 |
| 分数面板 | 顶部显示当前分数和最高分 |
| 状态提示 | 暂停/结束/开始等状态文字的叠加显示 |
| 颜色主题 | 经典绿蛇红果黑背景，保持视觉清晰 |

## 三、技术方案

### 3.1 技术栈
- **语言**: Python 3.10+
- **图形库**: Pygame（游戏循环、渲染、输入处理）
- **无其他第三方依赖**

### 3.2 项目结构

```
snack/
├── main.py            # 入口：初始化 pygame、启动游戏循环
├── config.py          # 常量：屏幕尺寸、颜色、速度、网格大小
├── game.py            # 游戏状态机：状态管理、碰撞检测、更新逻辑
├── snake.py           # 蛇实体：位置、方向、移动、增长
├── food.py            # 食物实体：随机生成、位置判断
├── renderer.py        # 渲染器：所有绘制逻辑的封装
├── score.py           # 分数管理：当前分、最高分、持久化存储
├── CLAUDE.md          # 本项目编码规范（供 AI 辅助开发参考）
└── plan.md            # 本文件：需求与技术方案
```

### 3.3 模块职责

| 模块 | 职责 | 对外接口 |
|------|------|----------|
| `config.py` | 集中管理所有可调参数 | 常量导出 |
| `snake.py` | 蛇的数据结构、移动逻辑、增长 | `Snake` 类 |
| `food.py` | 食物生成、位置随机化 | `Food` 类 |
| `score.py` | 分数读写、最高分持久化 | `ScoreManager` 类 |
| `game.py` | 游戏主逻辑、状态机、碰撞检测 | `Game` 类 |
| `renderer.py` | 所有 pygame 绘制调用 | `Renderer` 类 |
| `main.py` | 初始化、事件循环、帧率控制 | 入口脚本 |

### 3.4 游戏状态机

```
MENU ──→ PLAYING ──→ GAME_OVER
              │            │
              └── PAUSED ──┘
```

| 状态 | 行为 |
|------|------|
| `MENU` | 显示标题，按任意方向键开始 |
| `PLAYING` | 蛇移动、接受方向输入、碰撞检测 |
| `PAUSED` | 蛇停止、显示"暂停中"，按 Space 恢复 |
| `GAME_OVER` | 显示得分，按 R 重新开始 |

### 3.5 数据流

```
main.py (事件循环)
  ├── 读取键盘事件 → Game.handle_input()
  ├── Game.update()
  │     ├── Snake.move()
  │     ├── 检测碰撞（墙、自身、食物）
  │     ├── 吃到食物 → Snake.grow() + Food.respawn()
  │     └── ScoreManager.add_score()
  └── Renderer.draw(game_state)
        ├── draw_background()
        ├── draw_snake()
        ├── draw_food()
        ├── draw_score_panel()
        └── draw_overlay()  # 暂停/结束提示
```

### 3.6 关键设计决策

1. **网格对齐**: 蛇身和食物坐标以 CELL_SIZE 为步长，碰撞检测简单可靠
2. **方向缓冲**: 一个帧内多次按键只保留最后一次，防止"反向自杀"
3. **速度控制**: 使用 `pygame.time.Clock().tick(FPS)` 控制帧率，通过调整 FPS 实现难度变化
4. **最高分持久化**: 使用 JSON 文件存储到用户目录，跨游戏会话保持
